# Privacy policy

Effective date: 2026-11-16

This policy covers the megapowers plugin and its skills.

## What megapowers is

megapowers is a set of instruction text files (skills). It ships no
executable code, hooks, MCP server, telemetry, or network client.

## Data collected

The publisher, lawzava, collects no personal data through the plugin. The
publisher receives none, stores none, and shares none. There is no data to
retain and no recipient of data.

## Where your data goes

The agent product that loads the skills, for example Claude Code, ChatGPT,
or Codex, processes your content. That provider's own terms and privacy
policy apply. The skills run inside the permissions you grant that product.

Some skills guide the agent to ask another model for an independent review,
or to act outside your machine. These actions use only tools you already
configured and authorized. Before the agent sends material off-machine, the
skill text tells it to check for secrets and disclosure scope. Before an
outward effect, the skill text tells it to confirm authority for the exact
target. This is guidance to the agent, not enforcement.

If you open a GitHub issue or discussion, GitHub processes that data under
GitHub's own policies.

## Your controls

You choose whether to install the plugin and which permissions and tools
your agent product has. You can uninstall the plugin at any time; see
[docs/install.md](./install.md).

## Contact

Ask questions in
[GitHub issues](https://github.com/lawzava/megapowers/issues). Report
security problems as described in [SECURITY.md](../SECURITY.md).

## Changes

Changes to this policy are made through the repository history.
