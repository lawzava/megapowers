# Foundation review

For a design or material architecture review, give the reviewer the primary
requirements, current code path, and simplest sufficient alternative alongside
the proposal. Ask first whether the added entity or mechanism is needed, then
whether it is correct; do not use the plan's paraphrase as the sole source of
requirements. When restating primary requirements, preserve who is eligible,
when behavior starts, and explicit exclusions; check the source before
compressing those boundaries into a summary.
