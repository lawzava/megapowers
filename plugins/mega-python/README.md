# mega-python

Two skills for greenfield Python: project-shape-driven stack selection and
idiomatic Python patterns. No hooks; plain skills that work on any harness.

## What's inside

| Skill | What it gives you |
| --- | --- |
| `greenfield-python-stack` | Selects a current stack from project constraints, then gives a matching layout, async/DB baseline, and verification setup. |
| `python-patterns` | Idiomatic typing, async correctness, error handling, and concurrency patterns that don't deadlock. |

## Install

```
/plugin install mega-python@megapowers
```
